You can also use tools like Rufus if you want more control:

- Select your USB drive.
- Choose Windows 11 ISO.
- Set Partition scheme to GPT, Target system to UEFI (non-CSM).
- Format USB to NTFS but Rufus will handle the multi-partitioning for UEFI boot.
[Rufus - Create bootable USB drives the easy way](https://rufus.ie/en/)

> Rufus has been the easiest for me. Just download ISO and choose partition type.
