To print two-sided on an ---- in Windows 11, you must first ==enable the duplex unit in **Printer Properties** under **Device Settings**, then select the two-sided option in the document's print dialog under **Printer Properties/Preferences** or **Printing Preferences**==. For ongoing two-sided printing, you can set it as the default in the **Printing Preferences**.

Control Panel\Hardware and Sound\Devices and Printers --> right click -> printer properties -> general -> Device Settings -> installable options -> duplex unit or something, change it from "Not installed" to "installed" -> Apply
